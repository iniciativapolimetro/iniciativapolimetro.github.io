# iniciativapolimetro.github.io

Página web pública de Polimetro (`https://iniciativapolimetro.github.io`), publicada
automáticamente por GitHub Pages a partir de la rama `main` de este repo.

Publicar un cambio = editar `index.html` y hacer push a `main`; GitHub Pages
republica sola en unos minutos. No requiere build ni pasos intermedios.
